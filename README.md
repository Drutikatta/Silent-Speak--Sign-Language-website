# SilentSpeak

Silent Speak is a web-based platform that teaches **Indian Sign Language (ISL)** through a series of educational videos and quizzes. 
It’s designed to make ISL learning interactive, simple, and accessible — especially for beginners.
Silent Speak" is an online platform focused on teaching sign language. It provides interactive 
tutorials, videos, and gamified exercises for learners of all levels. The platform also fosters community 
engagement and cultural understanding. Through its user-friendly interface and adaptive learning 
features, Silent Speak aims to enhance communication inclusivity and empower users to express 
themselves fluently in sign language. 
 
## 📌 Features

- 🔐 User Login & Signup
- 📖 Information about Sign Language and ISL
- 📚 Structured Learning Modules (Beginner, Intermediate, Advanced)
- 🎥 Video Lessons
- 📝 Interactive Quizzes with Score Display

## 🚀 Getting Started

### Prerequisites
- Python 3.x installed
- `pip` for managing Python packages

### Steps to Run

```bash
# Clone the repository
git clone https://github.com/Drutikatta/Silent-Speak--Sign-Language-website.git
cd silentspeak final

# Optional: Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate  # On Windows

# Install dependencies
pip install -r requirements.txt

# Run the app
python app.py
